เริ่มการตรวจ

เลือกชนิดการตรวจให้เหมาะกับสิ่งที่ต้องการประเมิน

ข้อจำกัดที่ควรรู้

การตรวจ headers และ source code ทำใน browser; สแกนไฟล์ไวรัสต้องเปิด FastAPI/Celery/Redis/ClamAV ผ่าน Docker Compose เว็บนี้ไม่สามารถเข้าถึงไฟล์ทั้งหมดหรือแอปที่ติดตั้งในเครื่องได้

การตรวจเว็บไซต์ใช้คำขอ HEAD หนึ่งครั้งเท่านั้น เมื่อเชื่อมต่อ Backend จะส่งคำขอจาก Backend; ถ้าไม่มี Backend browser อาจอ่าน headers ไม่ได้หากเว็บไม่เปิด CORS ส่วนรายละเอียดใบรับรอง TLS ยังไม่ได้ตรวจ
ข้อมูล dependency (ชื่อและเวอร์ชันเท่านั้น) ส่งไปยัง OSV; source code วิเคราะห์ใน browser แต่ไฟล์สแกนไวรัสจะถูกอัปโหลดไปยัง backend เพื่อกักไว้ชั่วคราว

HTTP Headers

คำขอ HEAD หนึ่งครั้งผ่าน Backend (หรือจาก browser ซึ่งจำกัดด้วย CORS เมื่อไม่มี Backend)

พร้อม

TLS Certificate

browser ตรวจ TLS ขณะเชื่อมต่อ แต่หน้าเว็บนี้อ่าน chain และวันหมดอายุไม่ได้ ต้องเพิ่ม backend checker

ต้องมี Backend

กฎตรวจพื้นฐานทำงานใน browser; ไม่ execute และไม่อัปโหลด source

พร้อม

พร้อม

ยังไม่เชื่อมต่อ

Nuclei / Nmap / WPScan

ยังไม่ติดตั้งหรือเชื่อมต่อ; ไม่เปิดการสแกนเชิงรุกในต้นแบบนี้

ยังไม่เชื่อมต่อ
หากพัฒนาต่อ ควรให้ Backend ตรวจ ownership/allowlist และป้องกัน SSRF ก่อนส่งงานเข้า queue หรือเรียก scanner ใด ๆ

ตรวจการตั้งค่าเว็บไซต์

ส่ง HTTP HEAD request เพียงครั้งเดียวจาก browser เพื่อตรวจ security headers ที่อ่านได้ ไม่มีการ crawl หรือทดสอบช่องโหว่เชิงโจมตี

ใช้ได้เฉพาะเว็บไซต์ที่คุณเป็นเจ้าของหรือได้รับอนุญาต เมื่อเชื่อมต่อ Backend จะตรวจผ่าน Backend ซึ่งไม่ติด CORS; หากเปิดจาก GitHub Pages โดยไม่มี Backend browser อาจปฏิเสธการอ่านผลหากเว็บไซต์ไม่เปิด CORS และยังไม่ตรวจ chain/วันหมดอายุ TLS

วิเคราะห์ซอร์สโค้ด

ตรวจสัญญาณเสี่ยงทั่วไปในไฟล์ที่เลือกหรือโค้ดที่วาง โดยประมวลผลทั้งหมดใน browser ของคุณ
