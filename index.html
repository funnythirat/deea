ตรวจการตั้งค่าเว็บไซต์

ส่ง HTTP HEAD request เพียงครั้งเดียว เพื่อตรวจ security headers ที่ browser อ่านได้ ไม่มีการ crawl หรือทดสอบช่องโหว่เชิงโจมตี

วิเคราะห์ซอร์สโค้ด

ตรวจสัญญาณเสี่ยงทั่วไปในไฟล์ที่เลือกหรือโค้ดที่วาง โดยประมวลผลทั้งหมดใน browser ของคุณ

การวิเคราะห์นี้เป็นกฎพื้นฐาน ไม่ใช่ SAST เต็มรูปแบบ ผลที่พบเป็นเพียงจุดเริ่มต้นสำหรับการตรวจสอบด้วยคน
ผลการวิเคราะห์จะแสดงที่นี่

ตรวจสอบ dependency

อัปโหลด package-lock.json หรือ package.json เพื่อตรวจหาช่องโหว่ที่มีบันทึกใน OSV (Open Source Vulnerabilities)

จะส่งเฉพาะชื่อแพ็กเกจและเวอร์ชันไปยัง OSV เพื่อค้นหาข้อมูลช่องโหว่ ไม่ส่งไฟล์หรือ source code ทั้งหมด ช่วงเวอร์ชัน เช่น ^1.2.3 ต้องใช้ package-lock.json เพื่อให้ตรวจได้แม่นยำ
ผลการตรวจจะแสดงที่นี่

สแกนไวรัสและไฟล์ต้องสงสัย

ส่งไฟล์ที่เลือกเข้า quarantine เพื่อให้ ClamAV ตรวจ signature ใน worker; โหมดลึกจะเพิ่ม YARA heuristic scan พร้อมคำแนะนำหลังตรวจ

ข้อจำกัดของเว็บ: เบราว์เซอร์ไม่อนุญาตให้หน้านี้สแกนทุกไฟล์หรือทุกแอปในเครื่องโดยอัตโนมัติ สแกนได้เฉพาะไฟล์ที่คุณเลือก (สูงสุด 10 ไฟล์ต่อครั้ง, ไฟล์ละไม่เกิน 20 MiB) หากต้องการตรวจทั้งเครื่อง ให้ใช้โปรแกรมป้องกันไวรัสที่ติดตั้งในระบบปฏิบัติการ เลือกเฉพาะไฟล์ที่คุณมีสิทธิ์ตรวจ; ไฟล์ที่เลือกจะถูกส่งไปยัง backend นี้ชั่วคราว ห้ามอัปโหลดไฟล์ที่มีข้อมูลลับ ระบบไม่เปิดหรือรันไฟล์ และจะลบไฟล์ชั่วคราวหลังสแกน
