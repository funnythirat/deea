
# วิถีป้องกันรอบด้าน

เว็บต้นแบบช่วยคัดกรองความเสี่ยงเบื้องต้น หน้า Dashboard บน GitHub Pages กำหนดให้เข้าสู่ระบบด้วย Firebase Authentication แต่ไม่ต้องมี Backend เพื่อใช้ฟังก์ชันที่ประมวลผลใน browser/เครื่อง Windows

## ใช้งานได้ในตอนนี้

| ฟังก์ชัน | วิธีใช้และข้อจำกัด |
| --- | --- |
| วิเคราะห์ซอร์สโค้ด | เลือกไฟล์ที่ต้องการตรวจ การวิเคราะห์แบบ static ทำใน browser และไม่รันโค้ด |
| ตรวจ npm dependency | เลือก `package.json` หรือ `package-lock.json`; ส่งเฉพาะชื่อแพ็กเกจและเวอร์ชันไปยัง OSV เมื่อกดตรวจ |
| ตรวจรายงาน Wi-Fi | ใช้ [wifi-scan.ps1](./wifi-scan.ps1) บน Windows เพื่อสร้างรายงาน แล้วเลือกไฟล์ JSON บนหน้าเว็บ |
| สแกนไฟล์ด้วย Microsoft Defender | ใช้ [virus-scan.ps1](./virus-scan.ps1) บน Windows เพื่อสแกนไฟล์ในเครื่องและสร้างรายงานสำหรับเปิดในหน้าเว็บ |
| ตรวจ HTTP security headers | ส่งคำขอ `HEAD` หนึ่งครั้งจาก browser; ใช้กับระบบที่ได้รับอนุญาตเท่านั้น และ CORS ของเว็บไซต์อาจทำให้อ่านผลไม่ได้ |

แนะนำให้ตรวจไฟล์ PowerShell ก่อนเรียกใช้ และเลือกเฉพาะไฟล์/ระบบที่คุณมีสิทธิ์ตรวจ เครื่องมือนี้เป็นการคัดกรองเบื้องต้น ไม่รับประกันว่าจะพบภัยคุกคามหรือช่องโหว่ทั้งหมด

## ยังไม่พร้อมใช้งานบนหน้าเว็บสาธารณะ

หน้า GitHub Pages เป็น static site และยังไม่มี Backend URL ที่เชื่อมต่ออยู่ การสแกนไฟล์ด้วย ClamAV/YARA และการตรวจเว็บไซต์ผ่าน Backend จึงยังใช้ไม่ได้จนกว่าจะ deploy API/worker และผ่าน health check บัญชี Firebase ใช้เข้าสู่ Dashboard และยืนยันตัวตนกับ Backend เมื่อมีการเชื่อมต่อ การสร้างบัญชีไม่ทำให้ Backend พร้อมใช้งาน

ZAP, Nuclei, Nmap, WPScan, การสแกน TLS certificate ผ่าน Backend และการสแกนเครือข่ายเชิงรุกยังไม่อยู่ในขอบเขตที่เปิดใช้ ดูรายละเอียดที่ [ARCHITECTURE.md](./ARCHITECTURE.md) และ [DEPLOY-PRIVATE-VPS.md](./DEPLOY-PRIVATE-VPS.md) การ deploy Backend ในคู่มือนี้ออกแบบให้เข้าถึงผ่าน Tailscale แบบ private เท่านั้น

## ข้อมูลและความเป็นส่วนตัว

- โค้ดและรายงานที่เลือกวิเคราะห์ใน browser จะไม่ถูกอัปโหลดโดยอัตโนมัติ
- การตรวจ dependency ส่งชื่อและเวอร์ชันของแพ็กเกจไปยัง OSV ตามการกดยินยอม
- Firebase Authentication ใช้ควบคุมการเข้าหน้า Dashboard; ไม่เปิด Firebase Analytics
- การอัปโหลดไฟล์เพื่อสแกนผ่าน Backend จะส่งไฟล์ไปยังกักกันบน Backend เมื่อมีการตั้งค่าใช้งานดังกล่าว
